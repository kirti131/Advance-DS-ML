# Machine Learning & R Analysis Notebooks

This repository contains two Jupyter Notebooks — one for basic machine learning using Python, and another for data analysis using R.

## 📁 Files Included

1. **`xor_mlp.ipynb`**  
   - Demonstrates a neural network (MLPClassifier) using scikit-learn to solve the XOR problem.
   - Shows how a multi-layer perceptron can learn non-linear patterns.

2. **`iris_r_analysis.ipynb`**  
   - R-based analysis on the Iris dataset.
   - Includes outlier detection using the IQR method, handling missing values, mosaic plots, and linear regression.

## 🛠 Requirements

### For the Python notebook:
- `scikit-learn`
- `rpy2` (if R code is used within the Python notebook)

### For the R notebook:
- R packages: `vcd`, `ggplot2`, `lmtest`, `colorspace`, `zoo`

## 🚀 How to Run

- Run the Python notebook in Jupyter Notebook or Google Colab.
- For the R notebook:
  - Either enable R support in Jupyter (`rpy2`)
  - Or open it directly in RStudio for native R support
